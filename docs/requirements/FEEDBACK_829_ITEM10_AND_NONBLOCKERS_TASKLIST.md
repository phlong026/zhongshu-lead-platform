## C. 非阻塞事项二：生产多角色业务 UAT

### C1. 角色边界

- [ ] 超级管理员：公海池只读/维护边界、加盟商治理、资金页和审计；
- [ ] 运营人员：新增、逐行新增、飞书导入、补充资料、转池、派发、已处理；
- [ ] 电销人员：仅本人任务、提交事实结论、无派发和资金权限；
- [ ] 加盟商负责人：领取、人员分配、跟进、退回、积分与奖励；
- [ ] 加盟商员工：仅本人分配客资、跟进与补证；
- [ ] 加盟商角色访问公海池接口返回 403，页面无入口。
