## 最终门禁策略

锁住当前真实基线，防止覆盖率回退：

- global line ≥79.0%；
- global branch ≥54.5%；
- pytest-cov combined ≥74%；
- critical line ≥85.0%；
- critical branch ≥63.5%。

长期提升目标继续为 global branch ≥75%、critical line/branch ≥90%。后续补测试必须优先 reward/dispatch/points 的异常、权限、并发、幂等和边界路径，不做“刷数字”用例。
