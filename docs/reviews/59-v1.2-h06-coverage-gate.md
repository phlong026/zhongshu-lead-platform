# V1.2 Hardening H06：测试覆盖率门禁评审

- Hardening Issue：#55
- 父任务：#49
- 分支：`chore/v1.2-h06-coverage-gate`
- 风险等级：P2
- 当前状态：第一版门禁实现完成，等待真实 CI 基线

## 本次实现

1. Main Release Verification 的 backend tests 改为 pytest-cov line + branch coverage；
2. pytest-cov 综合 `--cov-fail-under=75`；
3. `check_coverage_gate.py` 独立计算 line 与 branch，明确要求 global line ≥75%、global branch ≥75%；
4. 输出 XML、JSON 和 critical modules 独立聚合报告；
5. coverage artifact 保留 30 天；
6. 高风险模块单独跟踪 auth / RBAC / points / return / reward / dispatch；
7. 高风险核心目标 line/branch ≥90%，第一轮基于真实 CI 确认基线后决定是否直接启用强门禁；
8. 新增脚本计算回归测试，防 line/branch 混算和 critical file 丢失。

## 质量原则

不允许通过 omit 高风险模块、skip H05 安全负例、只跑 happy path 或增加无价值测试来提高覆盖率。
