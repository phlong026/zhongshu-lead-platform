## 评审要点

1. **业务真实性**：列表仍使用 `/api/v1/dispatch/assignments` 的真实数据，不伪造客资等级或经营字段；Figma 中 A/B 等级仅作为后续质量评分能力的视觉预留，当前代码不展示没有数据支持的等级。
2. **筛选能力**：状态页签沿用原 API 查询；地区、来源和时间基于当前加盟商已返回的客资进行客户端筛选；关键词覆盖客户、地区、来源、业务类目与需求摘要。
3. **权限边界**：继续调用原加盟商公司级派发订单接口，不新增跨公司数据读取能力。
4. **事件兼容性**：原客资卡节点被移动和装饰，不复制替换，保留 `data-assignment` 及既有详情跳转事件。
5. **视觉一致性**：页面采用 V1.3 Token、状态色、圆角、搜索框、筛选器、提醒条和卡片结构，底部导航保持客资选中态。
6. **代码隔离**：列表能力拆为独立 CSS/JS，未扩大首页增强文件职责，支持单模块回滚。
7. **缺陷修复**：评审发现筛选按钮无动作，已修复为聚焦地区筛选控件。
