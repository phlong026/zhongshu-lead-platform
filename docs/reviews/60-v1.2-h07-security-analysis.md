## 当前阻断规则

- Semgrep：`ERROR`；
- Trivy：`HIGH` / `CRITICAL`；
- scanner 非 0 exit：阻断；
- Semgrep report `errors` 非空：阻断；
- 过期 waiver：阻断。

## Waiver 约束

每条必须包含 scanner、finding ID、scope、reason、owner、expires_on。过期 waiver 即使 finding 已消失也要删除/重新评审，避免历史例外永久留在仓库。
