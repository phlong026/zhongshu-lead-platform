## Scanner / rules / build 信任链最终设计

### Semgrep scanner

不再通过 pip 安装 scanner，也不再存在 `requirements-security.txt`。

执行主体固定为官方 Semgrep 1.172.0 linux/amd64 immutable digest：

`semgrep/semgrep@sha256:a8298d1c09c84b9a0bbc75ec915e37023fc4657360b6dbfa645261d2353a366c`

项目源码只读挂载，scanner 只获得预创建 `semgrep.json` 单文件写权限。

### Semgrep rules

不再使用运行时可变 Registry `p/security-audit` / `p/owasp-top-ten`。

规则固定到官方、签名验证通过的 `semgrep/semgrep-rules` commit：

`40b8c63f75dc7c22c8a77482d73bfb864b146f7e`

工作流：

- 仅 fetch 精确 commit；
- detached checkout；
- `rev-parse HEAD` 必须精确匹配；
- `git fsck --strict`；
- 保存 commit/tree hash evidence；
- 规则目录只读挂载。

固定安全规则覆盖当前技术栈的 Python lang / SQLAlchemy / FastAPI / boto3 / cryptography / JWT 与 JavaScript lang / browser / Express / audit。

恢复执行时确认 Semgrep 默认 ignore 会跳过测试目录，原工作流实际只覆盖 155/229 个应扫源码。工作流现固定关闭 scanner 默认 ignore，再由明确的非源码目录排除项限制范围；统一 gate 按源码根目录内 `.py` / `.js` 清单验证全覆盖。修复后本地扫描覆盖清单完整，无 scan error。

### SAST 工作树完整性

Semgrep 后执行 `git status --porcelain --untracked-files=all`；若 scanner/tooling 修改 tracked 或非忽略 checkout 内容，Docker build 前直接失败，避免安全 scanner 改写后续构建对象。

### Production base

Python production base 已固定 Bookworm linux/amd64 immutable digest，不再依赖漂移 tag。

### Trivy

执行主体固定为 Aqua Security Trivy 0.70.0 linux/amd64 immutable digest：

`aquasec/trivy@sha256:85e87be1a96459c38a4eea47dc64eb2d342bb14cd4b4cef96adcf6ff03378b7c`

候选生产镜像：

1. build；
2. `docker save` 冻结为 `app-image.tar`；
3. 记录 image_ref、完整 Docker ImageID、archive SHA-256；
4. Trivy 仅使用 `image --input` 扫该 tar；
5. 无 Docker socket；
6. input tar 只读；
7. 每次 Trivy 容器仅得到一个预创建 output file 的写权限，不挂整个 evidence 目录；
8. gate 后删除瞬时 tar。

## 最终 gate 语义

### Semgrep

- `results` / `errors` 数组必需；
- result 必须有 check_id / path / extra / severity；
- report errors 非空直接失败；
- `ERROR` finding 阻断，除非存在精确、有效、未过期 waiver。

### Trivy

- SchemaVersion=2；
- ArtifactType=`container_image`；
- ArtifactName == Trivy 固定 archive 路径 `/tmp/app-image.tar`；
- Metadata.ImageID == gate 从 legacy/OCI archive 闭环解析出的 config digest；
- Metadata.RepoTags 必须包含 scan subject image_ref；
- Results 为数组；
- Vulnerabilities 只能 null/array；
- HIGH / CRITICAL 阻断，除非存在精确 waiver。

### Scan subject / SBOM

- tar 实际 SHA-256 == `scan-subject.json`；
- ImageID 必须完整 SHA-256；
- legacy Docker archive 必须校验 config 内容 digest；
- OCI archive 必须从 `index.json` 的 subject ImageID 递归校验 descriptor digest/size，并证明 `manifest.json` config 可达；
- SBOM 必须 CycloneDX；
- components 必须非空；
- generator 必须 `aquasecurity/trivy` 0.70.0；
- metadata.component 必须 container；
- SBOM Reference / ImageID 必须与同一 scan subject 一致。

### Waiver

每条必须含 scanner、id、精确 scope、reason、owner、created_on、expires_on，并且：

- 禁止 `scope: "*"`；
- created_on 不能未来；
- expires_on 不能早于 created_on；
- 生命周期 ≤ 30 天；
- 过期/重复均失败。

恢复执行后的 exact 本地基线保留 31 个逐 occurrence 短期例外：

1. 6 个固定 argv、`shell=False` 的 Semgrep subprocess finding，最晚 2026-09-07 到期；
2. `cryptography 49.0.0` 单一 CVE，绑定 H12 #61，2026-08-21 到期；
3. 24 个 Debian Bookworm 系统包 High/Critical finding，当前 pinned base 与同代更新均无修复版本，逐 CVE/package/version/target 登记并在 2026-08-21 到期；补偿控制为非 root、drop capabilities、只读根文件系统及受影响路径不可达。

不得把这些 waiver 延伸为永久基线；基础镜像替换/重建或上游修复可用后必须立即删除。
