## 合并门禁

1. 对应测试必须通过；
2. Python 编译、JavaScript 语法、敏感信息和 `git diff --check` 必须通过；
3. 评审记录必须与实现同分支提交；
4. PR Diff 必须经过人工检查后才能合并；
5. 真实微信、飞书、PostgreSQL、对象存储和 TLS 属于生产上线 Gate，不以代码级测试替代。
