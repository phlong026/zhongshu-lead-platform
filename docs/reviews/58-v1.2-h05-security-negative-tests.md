## 实际修复

1. `upload_return_evidence` 在读取请求文件和写对象存储之前完成租户鉴权，跨公司 403 零文件/数据库副作用；
2. User 绑定 Company DISABLED 后既有 JWT 立即失效；API Principal 与 `/h5`/`/admin` Web entry 共享 `get_valid_session_user`；
3. Access Token、OAuth state、File Token 增加 canonical Base64URL JWT 检查，拒绝等价非 canonical token 表达；
4. Invite 一次性使用改为条件 `UPDATE ... used_at IS NULL ... RETURNING` 原子 compare-and-set，消除并发重放；
5. Points 同 idempotency key 在账户写序列化后重新查询幂等流水：PostgreSQL 使用 `FOR UPDATE`，SQLite 通过 no-op UPDATE 获取写序列化边界；
