# H5 与管理后台 SVG 图标系统迁移评审

## 迁移范围

- H5 页面：71 个 Emoji / Unicode 文本图标节点。
- 管理后台：278 个 Emoji / Unicode 文本图标节点。
- Design System：5 个底部导航组件图标节点。
- Figma 合计替换：354 个文本图标节点。

## Figma 结果

- H5 页面残留文本图标：0。
- 管理后台残留文本图标：0。
- Design System 残留文本图标：0。
- 所有替换节点均为可编辑 SVG 矢量，保留原尺寸、布局位置和文本颜色。
- 管理后台图标按照业务语义区分：看板、运营、导入、核验、合格、派发、公司、积分、充值、流水、退回、通知、账号、配置和审计。

## 代码实现

- 新增 `apps/h5/public/svg-icon-system.js`，提供本地内联 SVG 图标注册表与 DOM 增强器。
- 新增 `apps/h5/public/svg-icon-system.css`，统一 H5 与后台图标尺寸、对齐和交互规则。
- H5 与管理后台共用同一套图标定义，避免两端图标语义和描边风格漂移。
- 图标使用 `currentColor`，自动继承品牌棕、香槟金、状态色和选中态。
- SVG 使用 `aria-hidden="true"` 和 `focusable="false"`，按钮原有可访问名称保持不变。
- 不引入第三方图标库、外部 CDN、字体图标或远程资源。
- H5 首页复合按钮和快捷入口直接调用 `window.ZSIconSystem.svg()`，避免后续页面增强覆盖 SVG。

## 业务与安全边界

- 不修改客资、积分、退回、派发、通知和权限接口。
- 不修改数据库结构或迁移。
- 不增加网络请求和第三方依赖。
- 不改变按钮事件、路由、表单或状态机。

## 自动化检查

新增 `test_svg_icon_system.py`，验证：

1. H5 在业务脚本前加载 SVG 图标系统；
2. 管理后台复用同一套本地图标系统；
3. 图标为内联 SVG，并包含无障碍属性；
4. 不包含远程依赖；
5. 代码库中仍作为兼容输入存在的 Unicode 图标均有映射；
6. H5 复合消息按钮与快捷入口直接输出 SVG。

## 评审结论

通过。迁移仅改变图标表现层，保持原业务逻辑、权限和数据边界不变。
