# 46 - V1.2 Sprint 3 退回申诉与后置电销评审

- 分支：`feature/v1.2-sprint3-return-verification-backend`
- 目标分支：`release/v1.2.0`
- 任务：T18-T21
- 结论：待 PR 全量 CI 通过后可合并

## 1. 实现范围

### T18 退回申诉

- 仅支持四类冻结原因：
  - `EMPTY_NUMBER`
  - `OUT_OF_SERVICE_REGION`
  - `DUPLICATE_TO_RECEIVER`
  - `NON_HOUSING_CONSULTATION`
- 申诉截止统一读取领取时固化的 `appeal_deadline_at`；历史缺失时由工作日历按领取时间加 3 个工作日补算并固化。
- 初次提交必须在 3 个工作日内完成。
- 证据规则为截图或录音至少一项；后端按 `截图数 + 录音数 >= 1` 校验。
- 草稿与补充材料状态允许上传证据；初次提交逾期后标记 `EXPIRED`。
- 已按时提交后，管理员要求补充材料时可继续补充并发起下一轮核验，不因初始申诉截止已过而丧失既有申诉权。

### T19 申诉后创建核验任务

- 正常客资、供应商资料初审和人工派发均不创建前置电话核验任务。
- 仅退回申请提交后创建 `task_type=RETURN_VERIFY` 的核验任务。
- 申诉提交时：
  - 退回状态进入 `VERIFYING`；
  - 派发单进入 `RETURN_PENDING`；
  - 客资保持原 `CLAIMED/FOLLOWING` 状态，便于驳回时准确恢复；
  - 供应商奖励由 `OBSERVING` 冻结为 `FROZEN`；
  - 记录派发事件与审计。
- 重复提交不会创建第二个活动任务；补充材料后可创建下一轮任务。

### T20 后置电销事实核验

- 运营可查看并分配退回核验任务，受 `verification.read` 权限控制。
- 任务只能分配给有效 `TELESALES` 角色用户。
- 电销仅能领取未分配或分配给自己的任务。
- 电销提交：
  - 联系结果；
  - `SUPPORT_RETURN / DOES_NOT_SUPPORT_RETURN / INCONCLUSIVE` 事实结论；
  - 核验说明。
- 电销提交后退回申请进入 `REVIEWING`，但不能执行终审、返分或奖励处置。
- 只有任务归属人处于处理状态时可读取明文手机号；列表和其他角色只返回脱敏号码。

### T21 管理员终审

终审必须满足：

1. 退回申请处于 `REVIEWING`。
2. 当前 `RETURN_VERIFY` 任务已提交。
3. 电销事实结论完整。

终审结果：

- `APPROVE`
  - 按原领取实际扣分流水全额返分；
  - 使用 `v12-return:{return_id}:refund` 幂等键；
  - 派发单进入 `RETURNED`；
  - 客资清除当前派发引用并回到 `READY_DISPATCH`；
  - 供应商奖励由 `FROZEN/OBSERVING` 取消为 `CANCELLED`；
  - 已结算奖励阻止普通终审，后续进入 T24 异常冲正流程。
- `REJECT`
  - 不返分；
  - 派发单根据客资当前状态恢复到 `CLAIMED` 或 `FOLLOWING`；
  - 奖励由 `FROZEN` 恢复为 `OBSERVING`。
- `NEED_MORE`
  - 退回申请进入 `NEED_MORE_EVIDENCE`；
  - 派发单继续 `RETURN_PENDING`；
  - 奖励继续冻结；
  - 补充证据后创建下一轮 `RETURN_VERIFY`。

## 2. 与历史实现的隔离

V1.0.1 旧接口继续用于历史兼容，不在本次直接改写。V1.2 使用独立服务和 `/api/v1/v1.2/...` 路由，明确避免沿用以下旧规则：

- 48 小时退回窗口；
- 截图和录音双证据必传；
- 审核员跳过电销直接终审；
- 旧 `PENDING/NEED_MORE` 状态写入新业务数据；
- 通过退回后回到旧 `QUALIFIED` 状态。

## 3. 状态与事务边界

### 退回状态

`DRAFT → VERIFYING → REVIEWING → APPROVED/REJECTED/NEED_MORE_EVIDENCE`

补充材料：

`NEED_MORE_EVIDENCE → VERIFYING → REVIEWING`

初次逾期：

`DRAFT → EXPIRED`

### 原子性

- 申诉提交、任务创建、订单状态、奖励冻结和事件记录在同一事务。
- 电销提交、任务状态和退回状态在同一事务。
- 终审返分、订单回收、客资回池、奖励取消和事件记录在同一事务。
- 终审重复调用不会重复返分。

## 4. 安全评审

- 证据存入私有对象存储，限制 MIME、文件大小并记录 SHA-256。
- 证据读取采用绑定文件 ID 与用户 ID 的短时访问令牌。
- 供应商/接收方按公司归属读取退回申请；内部角色按权限读取。
- 电销任务列表不返回明文手机号。
- 只有当前任务归属电销可在任务详情或拨号接口读取手机号。
- 审计记录不包含明文手机号、密钥、令牌或对象存储签名。

## 5. 自动化测试

覆盖：

- 单张截图可以提交。
- 单份录音可以提交。
- 无证据提交被拒绝。
- 非冻结原因被拒绝。
- 正常流程在申诉前不存在核验任务，申诉后只创建 `RETURN_VERIFY`。
- 申诉提交冻结供应商奖励。
- 电销分配、领取、事实结论与状态推进。
- 未完成电销事实核验不得终审。
- 终审通过按实际扣分返分一次、回收客资、取消奖励。
- 重复终审不重复返分。
- 驳回恢复跟进状态并恢复奖励观察。
- 补充材料后创建第二轮核验任务。
- 初次提交逾期进入 `EXPIRED`。
