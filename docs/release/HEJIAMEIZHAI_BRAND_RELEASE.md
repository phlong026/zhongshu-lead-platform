# 合家美宅品牌上线说明

## 本次范围

- 用户可见品牌统一为“合家美宅”。
- 管理后台、加盟商 H5、电销核验台使用同一份合家美宅图标。
- 移除页面中的内部编号、版本装饰和重复的权限说明，保留必要的业务提示。

## 保持不变的内容

`ZHONGSHU`、`zhongshu` 等数据库、对象存储、日志与业务编码仍是内部兼容标识。本次不改动这些标识，避免影响已有数据、接口参数和生产运行环境。

## 上线验收

1. 打开 `/admin/`，确认登录页和后台页头显示“合家美宅”。
2. 在微信内打开 H5 首页，确认页头、登录页、状态页和浏览器标题显示“合家美宅”。
3. 打开电销核验台，确认页面标题显示“合家美宅”。
4. 检查三个页面的图标一致，且无白色底框。
5. 验证登录、客资列表、派发和邀请链接仍可正常使用。

## 回滚

如需回退，使用本次品牌提交执行 `git revert`，重新构建并按现有宝塔发布流程部署即可。内部数据与数据库结构未变，不需要数据回滚。
