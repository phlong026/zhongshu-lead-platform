# 众墅之家客资审核、派发与积分管理平台 V1.0.1 发布说明

## 版本定位

V1.0.1 是在 V1.0.0-P0 核心业务闭环基础上的生产候选版本，补齐真实微信与飞书集成、加盟商 H5 生产体验、积分体系、经营报表和生产部署能力。

本版本继续坚持：运营人工派发、线下付款后人工充值积分、单一积分账户。未加入自动派发、在线支付、微信小程序、云外呼或自动通话录音。

## 主要变化

### 微信生态

- 已绑定微信用户可直接 OAuth 登录，首次使用通过专属邀请完成加盟商公司绑定；
- 保存 OpenID/UnionID，支持账号、公司和邀请状态校验；
- 客资深链接增加用途、唯一标识、有效期、订单归属和状态校验；
- 订单回收、退回、过期或重新派发后旧链接即时失效；
- 微信通知 Outbox 支持失败重试、充值到账和低积分场景。

### 飞书客资同步

- tenant_access_token 缓存和到期刷新；
- 多维表格安全分页、增量拉取、字段映射、导入幂等和状态回写；
- 429、5xx、网络与 JSON 异常有限重试；
- 同步诊断接口、异常记录与命令行任务。

### H5 体验

- 微信登录保留原目标路由；
- API 超时和离线提示；
- 退回说明本地草稿；
- 截图与录音的格式、数量、大小和上传状态提示；
- 低积分状态、V1/V2/V3 等级和当前权益展示。

### 积分体系

- 充值档位与客资积分价格规则支持版本、生效和失效时间；
- 同一档位或同维度价格规则发布新版本时结束旧有效版本；
- 线下人工充值需要显式二次确认；
- 外部付款流水号和幂等键防止重复入账；
- 充值到账、赠送积分、等级权益作为流水快照；
- 低积分按公司和自然日去重提醒；
- 增加积分余额与不可变流水连续性对账接口。

### 经营报表

- 新增客资、核验、派发、领取、跟进、成交和退回漏斗；
- 新增领取率、跟进率、成交转化率和退回率；
- 新增区域客资、派发、成交和转化表现；
- 老板/财务角色可查看充值、消耗、返还和净积分变化；
- 运营角色服务端响应不包含财务积分字段。

### 生产工程

- 生产启动前校验 HTTPS、PostgreSQL、密钥、微信、飞书、Mock、CORS 和可信域名；
- 生产环境关闭自动建表，仅通过 Alembic 管理结构；
- JSON 结构化请求日志和请求 ID；
- API `Cache-Control: no-store`、CSP、HSTS 和其他安全响应头；
- TLS Nginx、请求限流、连接限制和 25MB 上传边界；
- API/Scheduler 非 root、只读根文件系统和最小 Linux 权限；
- 数据库与本地私有文件备份、SHA-256、保留策略和确认式恢复。

## 数据库与升级

部署时必须运行：

```bash
alembic upgrade head
```

生产环境设置 `AUTO_CREATE_SCHEMA=false`，禁止应用自行建表。升级前必须备份 PostgreSQL 和私有对象存储。

## 上线 Gate

正式开放前必须完成：

1. 真实微信公众号 OAuth、模板消息和深链接联调；
2. 真实飞书应用、多维表格字段映射、增量同步和状态回写；
3. 目标 PostgreSQL、私有对象存储、域名和 TLS 实证；
4. 数据库与证据文件联合恢复演练；
5. iPhone/Android 微信真机测试；
6. 3～5 家加盟商灰度试运行和积分对账；
7. 法务确认电话录音、聊天截图、隐私告知和数据保留规则。
