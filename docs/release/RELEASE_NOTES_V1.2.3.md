# 合家美宅客资平台 V1.2.3 发布说明

V1.2.3 基于 V1.2.2 的公海池、人工派发、退回申诉和异步导出主链，完成 2026 年 8 月 31 日六项运营反馈。该版本复用现有地区、权限、账务、通知和审计事实，不新增自动派发、在线支付或加盟商跨公司数据访问能力。

## 运营效率

- 创建或编辑加盟商时可按省、市、区县、乡镇/街道名称搜索全国标准地区，结果显示完整路径，点击后直接加入已选服务区域；原有四级联动、批量添加、去重和主要城市规则保持不变；
- 管理端客资总览新增“加盟商跟进人”。已明确分给员工时显示员工姓名，否则显示加盟商公司名称；平台只展示当前责任人，不开放加盟商内部交接、回收历史和员工任务清单；
- “后台导出完整手机号”调整为“导出客资完整信息”，补充客户需求、咨询类别、预算、当前加盟商跟进人、内部分配时间和最新跟进信息，完整手机号仍受权限、异步任务、文件过期和下载审计约束；
- 公海池支持按当前筛选结果或全部记录异步导出，并补充日期、录入人员筛选和重置。列表与导出共用同一成员判定，继续禁止在公海池执行派发、领取、跟进或退回动作。

## 证据上传与业务治理

- 加盟商退回继续执行“截图或录音任一项即可”的规则。多文件上传按单文件保存成功结果；只要已有一项证据成功，整批结束后即可提交，并逐项显示成功或失败原因；
- 新增单条客资 `is_test` 明确标记和 Alembic `0016_lead_test_flag` 迁移。仅超级管理员可在影响预览、完整客资编号、完整客户姓名和删除理由全部匹配后，永久删除从未派发的测试客资；
- 运营错派不使用硬删除。系统撤回当前派发并重新入池，返还积分、取消未结奖励、通知原加盟商并保留派发事件与审计记录；已完成、已终结、奖励已结算或存在有效退回流程的记录继续阻断撤回。

## 发布与验收边界

- 版本、运行时默认值、Docker OCI 标签、环境样例、发布清单、CI 分支和部署手册统一升级为 V1.2.3，禁止复用 V1.2.2 的不可变镜像身份；
- 自动化覆盖地区搜索、当前跟进人、退回证据部分成功、测试客资删除、错派撤回、积分/奖励/通知审计、完整客资导出和公海池筛选一致性；
- 生产切换仍必须先备份 PostgreSQL，显式执行迁移，校验数据库 revision、对象存储、容器健康和公网静态资源；
- 真实微信 WebView 上传、生产 PostgreSQL 并发锁、多角色业务 UAT、导出文件人工核验、灰度观察和最终 Go/No-Go 仍是独立验收门，不因代码、CI 或健康检查通过而自动完成。
