## 2. 代码交付结论

当前版本可以用于：

- 开发环境和测试环境部署；
- 业务方 UAT；
- 微信、飞书和对象存储真实联调；
- 2～5 家加盟商灰度试运行；
- 后续 P1 自动轮询派发开发的稳定基线。

当前版本不得被表述为“未经配置即可直接生产上线”，因为外部平台权限和客户真实业务参数不在隔离构建环境内。

## 4. 版本边界再次确认

P0 不包含：

- 微信、支付宝或其他在线支付；
- 保证金/钱包双账户；
- 自动派发、抢单、竞价和复杂权重；
- 加盟商内部员工二次派发；
- 云呼叫中心和 H5 自动录音；
- 独立 App 或微信小程序前端。
