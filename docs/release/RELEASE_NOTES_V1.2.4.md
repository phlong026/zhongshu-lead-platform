# 合家美宅客资平台 V1.2.4 发布说明

V1.2.4 基于 V1.2.3 的生产主链完成 2026 年 9 月 1 日客户反馈。本次不新增数据库迁移或第三方依赖，继续复用现有前置电销、权限、审计、异步导出和敏感文件到期清理能力。

## 客资录入与电销流转

- 新建平台客资默认仅保存草稿，不预选加盟商；运营可在同一表单选择“保存并派发电销核验”，只要手机号为有效 11 位号码，资料是否完整不再构成阻断；创建和派发由同一事务完成，并通过稳定幂等键防止双击或网络重试重复建档；
- 新建并直接派发加盟商保留为次级入口，不改变人工选定接收方和接收资格校验规则；
- 公海池为运营录入及飞书导入的草稿提供单条“分配电销核验”操作，不提供批量派发；手机号无效或查重结论未处理时阻断；
- 加盟商提供且因当地无可接收方留在公海池的客资不开放该入口。电销提交事实后仍回到运营处置，不能直接进入加盟商派发。

## Excel 导出

- 客资总览和公海池的异步导出统一生成单个 `.xlsx` 文件，不再向用户交付 ZIP/CSV 压缩包；
- 全部客资工作簿包含“客资明细”和“跟进记录”，公海池工作簿仅包含“公海池明细”；超量数据在同一工作簿内自动拆分工作表；
- XLSX 由 Python 标准库流式生成，未新增运行依赖；所有单元格按文本写入，阻断公式注入并保留完整手机号；
- 完整手机号权限、任务申请审计、下载审计、文件摘要、七天过期、租约续期和对象存储清理语义保持不变。

## 发布与验收边界

- 版本、运行时默认值、Docker OCI 标签、环境样例、发布清单、CI 分支和部署手册统一升级为 V1.2.4，禁止覆盖 V1.2.3 的不可变镜像与发布证据；
- 自动化覆盖新建直派电销、公海池单条派发、飞书导入电销闭环、无效手机号、未决查重、XLSX 内容、分片、下载头、租约和敏感文件清理；
- 生产切换必须先完成 PostgreSQL 备份和对象存储写入/读取/删除探针，再更新 API、导出 Worker、Scheduler 与 Nginx；
- 公网健康、真实 XLSX 下载及运营/电销角色业务验证通过后，才能将 V1.2.4 标记为生产可用。
