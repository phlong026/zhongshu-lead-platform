# 众墅之家客资平台 V1.2.0 发布说明

## 发布定位

V1.2.0 将平台从 V1.0.1 的内部导入与派发流程扩展为平台手工供给、加盟商供应、人工派发、退回后置核验和供应商奖励的完整闭环。

## 核心新增

### 客资供给和去重

- 平台手工客资草稿、编辑、提交；
- 供应商 H5 上传、列表和详情；
- 公司 `LEAD_SUPPLIER` / `LEAD_RECEIVER` 能力及服务区域审核；
- 独立手机号 HMAC-SHA256 指纹；
- 90/180/365 天动态去重窗口、历史关系和人工覆盖审计；
- 供应商客资资料初审。

### 人工派发和领取

- `READY_DISPATCH` 待派发池；
- 区域、能力、积分、自供自领和历史重复候选筛选；
- 仅平台人工派发；
- 派发预留但不扣分；
- 领取、扣分、联系方式解锁、3 工作日申诉截止和奖励快照同事务；
- 数据库层同客资单有效派发单约束。

### 退回申诉和后置核验

- 空号/停机、超服务区、接收方重复和非建房咨询四类原因；
- 截图或录音至少一项证据；
- 仅申诉提交后创建 `RETURN_VERIFY`；
- 电销事实核验与管理员终审分权；
- 通过时一次返分、客资回池和奖励取消；
- 驳回时恢复跟进和奖励观察；
- 补证支持多轮核验。

### 供应商奖励

- 规则比例、最低/最高积分、去重窗口和版本快照；
- 3 工作日观察；
- 每小时有界结算、失败隔离和幂等流水；
- 申诉冻结与驳回后即时结算；
- 欺诈、系统错误和管理员错误异常冲正；
- 负积分债务支持，保留原流水关联。

### 前端、通知和审计

- `/h5/v12-workbench.html` 加盟商全链路工作台；
- `/admin/v12-operations.html` 平台运营台；
- 业务状态变化事务内生成站内消息与 Outbox；
- 微信业务深链；
- V1.2 经营报表、本公司报表、审计查询和业务 ID 追踪；
- 审计快照递归脱敏手机号、授权头、Token、Cookie 和密钥。

## Sprint 6 上线准备

- 历史手机号指纹有界、幂等、断点续跑回填；
- 未知历史状态严格识别；
- 积分、派发、退回、奖励和证据数据对账；
- PostgreSQL 16 历史升级 CI；
- Chromium 桌面后台和移动 H5 自动交互/截图门禁；
- 飞书显式可选，生产密钥与手机号指纹密钥强化；
- 生产 API 禁止隐式迁移；
- V1.2 迁移、UAT、Go/No-Go、回滚、备份恢复和灰度 Runbook。

## 不包含

- 自动、随机、轮询、权重或抢单派发；
- 在线支付；
- 微信小程序；
- 云外呼；
- H5 自动录音；
- 加盟商内部二次派发。

## 升级要求

1. 使用 PostgreSQL 备份副本完成全量预演；
2. 独立配置 `PHONE_FINGERPRINT_SECRET`；
3. 写入冻结后备份并显式执行 Alembic；
4. 运行 `migrate_v12_data.py`；
5. 运行 `reconcile_v12.py` 并确保 valid；
6. 完成真实微信联调、UAT、恢复演练和 3–5 家灰度；
7. 依据 `V1.2_GO_NO_GO.md` 多方签字。

## 兼容说明

- V1.0.1 历史状态以只读映射方式展示，不批量覆盖原始业务事实；
- V1.0.1 `RETURN_WINDOW_HOURS=48` 仅保留旧接口兼容，V1.2 申诉使用工作日历；
- 生产镜像应使用不可变 digest；
- 实际生产开放时间以真实环境 Go/No-Go 结果为准。
