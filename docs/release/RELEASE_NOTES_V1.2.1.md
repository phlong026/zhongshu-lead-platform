# 合家美宅客资平台 V1.2.1 发布说明

V1.2.1 是 V1.2.0 代码候选后的上线交付修复版，重点收口业主交付前发现的业务口径、发布元数据和生产门禁问题。真实微信、正式基础设施、业主 UAT、备份恢复演练和灰度开放仍以目标环境证据为准。

## 本版修复

- 退回证据口径回到 PRD 冻结语义：沟通截图或电话录音任一类型满足即可；
- 公司快速创建不再绕过接单资质和服务区域的申请/审核闭环；
- 移除后台飞书暂存物理删除入口，仅保留只读概览，避免误删历史客资；
- 每日调度周期按 30 秒 tick 的真实 24 小时执行，避免一天重复跑两次；
- 已批准的城市级服务范围可覆盖其直属区县客资，并补充派发候选回归测试；
- 仓库密钥扫描仅检查 Git 已跟踪文件，降低虚拟环境噪音并覆盖核心生产密钥；
- 发布候选统一为 `V1.2.1`，覆盖 `pyproject`、环境样例、Docker 默认版本、发布清单、CI 打包参数和生产检查表；
- main-release、PR CI、release CI 统一调用 `scripts/check_release_metadata.py`，防止版本、品牌和发布资料漂移；
- 生产检查表增加 `scripts/check_binding_integrity.py` 证据项，要求上线前归档主账号/邀请绑定完整性检查结果。

## 交付边界

- V1.2.0 历史评审、测试报告和归档说明保持不改，作为历史证据继续保留；
- 本说明仅声明 V1.2.1 当前候选的修复范围，不代表生产 Go-Live；
- 上线前仍必须完成服务号网页授权、不可变镜像摘要、PostgreSQL 迁移/对账、对象存储、UAT、回滚演练和灰度签字。
