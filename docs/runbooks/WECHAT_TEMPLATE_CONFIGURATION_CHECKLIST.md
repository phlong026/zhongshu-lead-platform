# 微信服务号模板消息配置清单

适用范围：众墅之家平台向**已关注服务号、且已经完成微信授权绑定的加盟商负责人**发送重要业务通知。

本清单不用于营销群发；未绑定微信的邀请对象没有 OpenID，仍由运营人员通过邀请链接或二维码发送。

## 1. 公众号后台操作

在微信公众平台的「广告与服务 → 模板消息」页面依次完成：

1. 确认账号为已认证服务号，模板消息功能可用。
2. 进入「模板库」，按每个场景的关键词选择**实际字段足够匹配**的服务通知模板。
3. 添加后，在「我的模板」中复制 `模板ID`，并逐字抄录模板字段名。
4. 不要假设字段一定叫 `keyword1`、`keyword2`；字段名必须和「我的模板」展示的一致。
5. 保留每个模板的截图或导出记录，供上线前复核。

## 2. 首批上线场景

| 平台事件 key | 给谁发 | 模板应表达的内容 | 建议跳转页 |
| --- | --- | --- | --- |
| `V12_ASSIGNMENT_DISPATCHED` | 被派发客资的加盟商负责人 | 新客资、服务地区、领取截止时间 | 待领取客资列表 |
| `V12_ASSIGNMENT_CLAIMED` | 已领取客资的加盟商负责人 | 领取成功、客户地区、下一步跟进时限 | 我的客资详情 |
| `V12_RETURN_APPROVED` | 提交退回申诉的加盟商负责人 | 申诉已通过、处理时间、结果说明 | 退回申诉详情 |
| `V12_RETURN_REJECTED` | 提交退回申诉的加盟商负责人 | 申诉未通过、原因、补证或后续提示 | 退回申诉详情 |
| `V12_RETURN_NEED_MORE` | 提交退回申诉的加盟商负责人 | 需要补充材料、截止时间、补充说明 | 退回申诉详情 |
| `V12_SUPPLIER_REWARD_SETTLED` | 获得奖励的加盟商负责人 | 奖励到账、金额或积分、结算时间 | 供客奖励列表 |

`V12_SUPPLIER_LEAD_SUBMITTED`、`V12_RETURN_SUBMITTED` 等面向平台审核人员的事件，先保留站内消息；只有在审核人员也具备有效 OpenID 和明确的服务号订阅关系后，才能单独启用微信模板。

## 3. 平台模板配置

每个场景在超级管理员权限下创建一条已发布系统配置：

```json
{
  "domain": "wechat_template",
  "key": "V12_ASSIGNMENT_DISPATCHED",
  "value": {
    "template_id": "lY0K9b-7pB0bOnfjOJ6zPvPeL5fm0DjPhjxhRUZt3MU",
    "field_map": {
      "thing1": "body",
      "const16": "literal:乡墅新客资"
    }
  },
  "publish_immediately": true
}
```

`field_map` 的左侧是公众号「我的模板 → 详情 → 详细内容」中的原始字段键（例如 `thing1`、`const16`），不是页面展示的中文标签；右侧只能使用以下业务值：

| 右侧值 | 平台写入的内容 |
| --- | --- |
| `title` | 此次通知的业务标题 |
| `scene` | 平台事件 key，用于审计与排障 |
| `body` | 该笔业务的地点、时限、原因或结果摘要 |
| `remark` | 固定的“点击查看详情”提示 |
| `literal:固定文案` | 为类目模板的常量关键词写入固定文字，例如 `literal:乡墅新客资` |

旧配置只有 `template_id` 时，系统继续按 `first`、`keyword1`、`keyword2`、`remark` 的默认映射发送；新模板应始终显式填写 `field_map`，避免换模板后字段错配。

## 4. 上线前验证

1. 生产环境配置有效的 AppID/AppSecret，`WECHAT_DEV_MOCK=false`，并确认网页授权域名、回调地址与正式 HTTPS 域名一致。
2. 使用一个测试加盟商负责人账号：关注服务号、完成微信授权绑定，并确认平台可查到其 OpenID。
3. 配置一个真实 `template_id`，先只触发一条 `V12_ASSIGNMENT_DISPATCHED` 测试客资。
4. 执行 Outbox 作业，检查消息到达、字段内容、点击跳转、登录回跳和客资权限校验。
5. 同时测试未关注、未绑定、模板字段配置错误和微信接口失败；这些任务应分别留下可处理的失败记录，不得静默丢失。
