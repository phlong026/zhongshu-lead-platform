# V1.2 Go / No-Go 门禁

## 1. 判定规则

- 所有“必须”项通过才可判定 `GO`；
- 任一项缺少可核验证据，视为未通过；
- 代码自动测试不能替代真实微信、真实对象存储、业务 UAT、恢复演练或灰度结果；
- 决策由产品、业务、财务、技术和发布经理共同签字。

## 3. 自动证据命令

```bash
python scripts/preflight_v12.py \
  --env-file .env \
  --require-certificates \
  --output dist/v12-preflight.json
```

该命令检查生产配置、部署文件、Alembic head 和 V1.2 数据对账。以下证据仍需人工附加：

- CI 与代码评审链接；
- 真实微信和飞书联调；
- 浏览器/设备报告；
- UAT 签字；
- 备份恢复演练；
- 监控告警截图；
- 法务与业务审批。

## 4. 上线停止条件

上线窗口出现以下任一情况立即 `NO-GO` 或回滚：

- 数据库迁移失败或超过预演时长 150%；
- 指纹回填存在失败行；
- 积分、返分或奖励对账不为 0；
- OAuth、领取、扣分、退回、结算任一核心链路失败；
- 手机号、Token、证据或财务字段越权；
- 5xx、数据库连接、磁盘或 Scheduler 告警达到红线；
- 上线前备份不可验证；
- 关键责任人不在线。
