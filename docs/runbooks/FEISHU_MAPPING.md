# 飞书“客户视图”到公海池字段映射

一期只支持运营在管理后台手动触发单向导入。系统读取配置数据表中的精确“客户视图”，不创建定时任务，也不向飞书回写。

默认读取字段：客户姓名、手机号、省、市、区县、地区编码、业务类目、品牌、来源渠道、具体来源、客户需求、预算下限、预算上限、获客成本、已获客户授权。

目标池按批次统一选择：

- `PUBLIC_POOL`：全部新增记录留在公海池；
- `DISPATCH_POOL`：完整且查重未阻断的记录进入派发池，其他记录自动留在公海池并保留原因。

正式上线前应：

1. 锁定 `app_token`、`table_id` 与 `view_id`，或保证数据表内只有一个名称精确等于“客户视图”的视图；
2. 为应用授予视图与记录只读权限，不授予业务所不需要的更新权限；
3. 使用 `app_token + table_id + record_id` 作为数据库唯一来源键；
4. 验证客户视图过滤、分页、Token 续期和限流重试；
5. 不使用表格行号作为唯一标识；
6. 字段变更先在测试表完成映射回归；
7. 生产必须设置 `FEISHU_WRITEBACK_ENABLED=false`，且不得为本功能配置定时同步。

手机号在保存前会标准化，并再次与系统内客资查重。公海池转入派发池时会重新校验姓名、手机号、标准地区、来源、授权、预算范围与查重结论，不能依赖导入时的旧结果。
