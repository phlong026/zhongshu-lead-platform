# V1.2 安全上线检查表

## 密钥与配置

- [ ] 所有生产密钥通过密钥管理系统注入且不在 Git、镜像、日志或交付包中；
- [ ] `JWT_SECRET`、`FIELD_ENCRYPTION_KEY`、`PHONE_HASH_SECRET`、`PHONE_FINGERPRINT_SECRET` 均满足长度要求；
- [ ] `PHONE_HASH_SECRET` 与 `PHONE_FINGERPRINT_SECRET` 独立；
- [ ] 密钥备份、访问审计、轮换和紧急吊销流程已验证；
- [ ] `SEED_DEMO=false`，演示账号和默认密码不存在；
- [ ] 微信、飞书模拟开关关闭，飞书启用状态与凭据一致。

## 网络与会话

- [ ] 仅 HTTPS 开放业务访问，HTTP 强制跳转；
- [ ] Secure、HttpOnly、SameSite Cookie 生效；
- [ ] CORS 和 Trusted Hosts 仅允许正式域名；
- [ ] PostgreSQL 与对象存储管理接口不暴露公网；
- [ ] SSH、云控制台和数据库管理使用最小权限、MFA 和白名单；
- [ ] Nginx 限流、上传限制、安全响应头和 TLS 配置通过扫描。

## 权限与数据隔离

- [ ] 运营和电销接口不包含实收金额、收入、成本、毛利或未授权积分余额；
- [ ] 完整手机号仅对任务归属电销、成功领取的所属加盟商和必要审核角色开放；
- [ ] 领取前、列表和通知中手机号均脱敏；
- [ ] 供应商和加盟商只能访问本公司数据；
- [ ] 跨公司业务深链返回无权且不展示客资摘要；
- [ ] 敏感权限、高风险操作和终审均有审计；
- [ ] 审计、错误栈和日志递归脱敏手机号、Token、Cookie、授权头和密钥。

## 文件与对象存储

- [ ] 截图和录音对象默认私有，不存在永久公网 URL；
- [ ] 文件类型、MIME、大小、文件名和 SHA-256 校验通过；
- [ ] 越权读取和过期授权链接均失败；
- [ ] 私有桶启用服务端加密、版本、访问审计和生命周期；
- [ ] 上传恶意样本、空文件和伪造 MIME 的安全测试通过。

## 账务与并发

- [ ] 积分变动使用数据库事务、业务唯一键和不可变流水；
- [ ] 重复派发、领取、充值、返分、奖励结算和冲正均有幂等保护；
- [ ] PostgreSQL 并发测试确认同一客资最多一个有效派发单；
- [ ] 奖励冲正关联原流水，不能删除或覆盖历史流水；
- [ ] `reconcile_v12.py` 返回 valid，积分、奖励和返分差异为0。

## 供应链和运行安全

- [ ] Python 依赖、容器镜像和操作系统无未接受的 Critical/High 漏洞；
- [ ] 镜像使用受控仓库和不可变 digest；
- [ ] 容器以最小权限、只读根文件系统、cap drop 和 no-new-privileges 运行；
- [ ] 结构化日志、5xx、Outbox DEAD、Scheduler、磁盘、备份和证书告警生效；
- [ ] 数据库、对象、密钥和应用的联合恢复演练通过；
- [ ] 安全事件联系人、隔离、密钥轮换、证据保全和合规通知流程已发布。
