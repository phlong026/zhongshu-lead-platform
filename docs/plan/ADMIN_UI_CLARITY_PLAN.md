# 管理后台信息降噪与图标系统改进计划

## 真实需求

这次调整不是重做品牌风格，而是降低后台首屏噪音，并让图标在所有管理后台页面保持一致、可理解：

1. 权限说明不应以高权重绿色提示条占用首屏空间；
2. 顶部账号区不应重复展示姓名和角色编码，只保留可识别头像；
3. 图标必须由明确的业务语义驱动，不能继续依赖 Unicode 字符和 DOM 文本猜测。

## 现状诊断

- `admin-design-system-v10.js` 会在每个后台页面标题下插入 `.adm-v10-scope` 提示条。它重复页面副标题的信息，并把指标卡整体下推。
- `app.js` 在顶部同时展示 `display_name`、角色编码、头像和退出按钮，身份信息重复且暴露内部角色代码。
- 主后台先输出 `⇩`、`☎`、`↗`、`◈` 等字符，再由 `svg-icon-system.js` 的 `MutationObserver` 猜测并替换为 SVG。最终格式虽是内联 SVG，但语义依赖文本启发式，容易出现“待领取=外链”“合格客资=普通列表”等错配。
- 原 `v12-leads.html` 已删除并迁入 `v12-operations.html`；统一运营台使用共享 SVG 图标系统，避免独立页面造成图标表现不一致。

## 设计决策

### 1. 页面说明降噪

- 删除 `.adm-v10-scope` 提示条及其绿色、黄色、普通变体。
- 保留页面标题下的一行中性副标题，权限与敏感字段仍由后端 RBAC 控制，不用高权重视觉容器重复声明。
- 原本依赖提示条定位的统计增强组件改为跟随页面标题插入。

### 2. 头像化账号入口

- 顶栏常驻区域只显示 40px 圆形头像，不显示姓名、角色中文名或角色编码。
- 头像是可聚焦按钮，具备 `aria-label`、`aria-expanded` 和清晰焦点态。
- 点击头像仅展开轻量账号菜单，菜单保留“退出登录”这一必要操作，不重复展示角色信息。

### 3. 显式 SVG 图标

- 继续复用现有本地内联 SVG 注册表，不新增依赖、不使用远程 CDN。
- 管理后台和 H5 业务脚本都直接按图标名称渲染 SVG；Unicode 映射只保留在共享图标系统内部作为兼容层，不再由业务页面输出。
- 统一 24×24 画布、`currentColor`、圆角端点与 1.8px 描边。
- 业务语义固定为：
  - 暂存待处理：`inbox`
  - 待核验：`phone`
  - 合格客资：`user-check`
  - 待领取：`hand-claim`
  - 积分总余额：`coins`
  - 菜单与独立工作台：使用明确的看板、公司、流水、通知、审计等命名图标

## 验收标准

- 页面标题下不再生成 `.adm-v10-scope` 提示条；首屏指标卡上移。
- 顶栏 DOM 不再常驻输出用户姓名和角色代码；头像按钮可打开退出菜单并支持键盘焦点。
- 主后台、客资供给工作台和全链路运营台都在业务脚本之前加载同一套本地 SVG 图标资源。
- 管理后台和 H5 业务脚本不再以旧 Unicode 字符作为菜单、指标、操作或空状态图标。
- 图标语义、尺寸、描边和颜色继承规则通过自动化测试锁定。
- 不修改 API、权限、数据范围、路由、业务状态机或数据库。

## 验证与回滚

- 先运行针对设计系统、图标系统和前端契约的回归测试，再运行完整相关测试与静态检查。
- 使用浏览器分别检查桌面与窄屏下的看板、头像菜单、主侧栏和 V1.2 独立页面。
- 变更仅涉及静态 HTML/CSS/JS 与契约测试，可通过单次 `git revert` 完整回滚。
